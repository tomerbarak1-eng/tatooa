# TATOOA: אב־טיפוס MVP

אב־טיפוס לחיץ של TATOOA, מרקטפלייס דו־צדדי שמחבר בין לקוחות לאמני קעקועים (קבוצה 12: תומר ברק, שוהם אטיאס ושירי שלל).

## איך פותחים
פותחים את `index.html` בדפדפן (Chrome מומלץ). אין התקנה ואין שלב בנייה.

## מה יש באב־הטיפוס
**צד הלקוח:**
1. **סטודיו הדמיה:** בוחרים אזור בגוף (אמה, כתף, שוק) או מעלים תמונה, ובוחרים סקיצה מובנית או מעלים אחת (הרקע הלבן מוסר). גוררים, משנים גודל, מסובבים ומשנים שקיפות. יש מצב Cover-Up ושיתוף (התמונה כוללת סימן מים).
2. **הערכת מחיר:** לפי גודל, סגנון, מיקום, מורכבות, צבע ו-Cover-Up, עם התראה על תקציב לא ריאלי.
3. **התאמת אמנים:** 5 אמנים לדוגמה, ממוינים לפי סגנון, תקציב ודירוג.
4. **בקשה להצעת מחיר:** הצהרת גיל 18+ ותנאי שימוש, והסבר על המקדמה (15% / 85%) ועל ביטוח הקעקוע.

**צד האמן/ית (אזור אמנים):** תיבת פניות עם "תיק לקוח" לכל פנייה. אפשר לאשר, להציע מחיר או מועד אחר, או לדחות. אחר כך מדמים סליקת מקדמה, ורק אז נפתח הסטנסיל הנקי ללא סימן מים. משם שולחים הצהרת בריאות והוראות טיפול.

## מה מדומה (לא אמיתי)
- כל האמנים, המחירים והמכפילים הם **נתוני הדגמה**. טבלת המחירים תוחלף בסקר של כ־50 אמנים.
- אין שרת: הפניות נשמרות ב־localStorage של הדפדפן בלבד.
- תשלום המקדמה, אימות הרישיון ושליחת הטפסים הם סימולציה.
- AR/LiDAR, ניתוח גוון עור ומחשבון דהייה מופיעים כ"בקרוב".
